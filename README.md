# シンプルになろう（バックアップ） v1.0.0

小説家になろうの自作品・下書き・設定・ブックマーク・お気に入りユーザ・自分の活動報告を、ローカルのZIPへ保存するChrome拡張です。保存済みの文章は、付属の「シンプルになろう（ビューワー）」で確認・コピーできます。

対応は一般向けの小説家になろうのみです。Xユーザホーム・カクヨム・他サイト・公式バックアップZIPの読み込み・サイトへの自動復元には対応していません。パスワード・Cookie・読者コメント・運営のお知らせを保存しません。外部の画像・音楽・動画本体は対象外で、挿絵コードやURLを原文に残します。

## Chromeへの登録

1. 配布ZIPを展開します。
2. Chromeの拡張機能管理画面で「デベロッパーモード」をオンにし、「パッケージ化されていない拡張機能を読み込む」から、manifest.jsonのあるフォルダを選びます。
3. なろうのログイン済みユーザーホーム、または自作品一覧を開き、拡張アイコン「な」を押します。

更新時は取得を終了し、登録済みの同じフォルダの中身を新版へ置き換えて拡張を再読み込みします。取得元タブと詳細タブも再読み込みしてください。別フォルダで新規登録すると記録・権限が別管理になる場合があります。更新前に既存データを保存してください。

## 全てをダウンロードする

1. トップエリアの利用者IDを確認します。
2. 「ダウンロード設定」で保存先フォルダ、保存形式、必要なら「ビューアー専用HTMLも保存する」を設定します。
3. 取込詳細設定の「ZIPの分割」で、分割しない／5MBごと／デバッグ：1MBごとを選びます。初期値は分割しないです。
4. 「全てをダウンロードする」を押します。本文・設定・その他情報を、標準ペースでZIPへ順次保存します。
5. 取得元タブ・詳細タブ・Chromeを開いたまま待ちます。PCのスリープ中は取得できません。
6. 完了後、保存したZIPを読み込み、内容と不足・破損の警告を確認します。

標準は5〜8秒ごとに1ページ、30ページごとに1分30秒休んで自動再開します。この間隔で通信制限を必ず回避できるという保証はありません。通信エラー・ログイン切れでは停止します。「一時停止」「取得再開」を使えます。

保存先は拡張内で記憶します。Chromeから書き込み許可の再確認を求められる場合があります。同名ファイルは上書きしません。

## ZIPの名前と分割

日時は日本時間です。例：

- `793702-simple-narou-backup-20261008-180000-001.zip`：作品一覧、作品本文・設定・章設定、取得結果など。
- `793702-simple-narou-backup-20261008-180000-000.zip`：ブックマーク、カテゴリ、お気に入りユーザ、活動報告、共通テンプレート。
- 分割時、作品は001、002、003…へ続きます。その他情報が大きい場合は000、000-002、000-003…へ続きます。

「分割しない」でも作品とその他情報は別ZIPです。その他情報が保存対象に存在しなければ000は作成しません。1件の原稿や管理情報だけで指定サイズを超える場合は、原稿を分断せず上限超過を許容します。5MBは5×1,048,576バイト、デバッグ用は1,048,576バイトが目安です。

同じ保存操作のZIPを、000も含めてまとめて読み込んでください。順番は問いません。内部の識別子と管理情報で不足を判定します。欠けたファイルがあっても、ある文章は確認できますが、全体完了や取得再開の対象にはしません。ファイル名を変更しても管理情報は変わりません。

## 個別取得・選択した対象の保存

「作品一覧を取得」後、「全部保存」または作品を1つ選び、「取得開始」または「再取得」を押します。その他情報をオンにすると、1作品の選択時もアカウント全体のその他情報を読みます。同一内容は連続して履歴を増やしません。

個別取得はブラウザ内の履歴（上限10MB）に保存します。ZIP直接取得は原稿をブラウザ内へ溜めません。取得後は「JSONで保存」「テキストで保存」「ZIPで保存」で書き出してください。

「全部保存」では保存元の全履歴、作品の選択時はその作品の本文・設定・判別可能な編集履歴・関連付け済みの活動報告を対象にします。作品別の「ZIPで保存」では「その他情報」がオンの場合、同じアカウントの保存済みその他情報も000へ保存します。JSON・テキストの作品別保存は選択した作品の履歴のみです。本文・設定チェックは取得範囲を指定します。

保存元は下の確認エリアに表示しているデータです。ZIP／JSONを読み込んでいればそのファイル、通常時はブラウザ内のデータです。「ブラウザ内の一覧を表示」でインポート表示を解除します。作品別の書き出しには全体の取得再開情報を含めません。

## 一時停止・再開・リセット

詳細タブが開いている間は同じZIPへ取得を再開できます。タブを閉じると取得元へ停止を要求します。開き直した後は途中までのZIPをすべて読み込み、「取得再開」で新しい名前のZIPへ保存済み分をコピーして続けます。元のZIPは残ります。不足・破損があるZIPからは再開できません。

各ZIPは書き込みの確定後に取得元へ成功を返します。終了処理中に中断した場合は完了表示にならない場合があります。OS・ディスク障害や処理中の1ページの保存を保証するものではありません。

「取得データをリセット」は拡張内の全アカウントの原稿・履歴・再開情報・関連付けとインポート表示を消します。確認後に実行し、取得中・休憩中・書き込み中は使えません。保存済みファイル、保存先フォルダ、ダウンロード設定・公式設定の控えは残します。

## シンプルになろう（ビューワー）

`simple-narou-zipviewer.html` を開き、ZIP／JSONをD&Dするか、「ZIPのあるフォルダを読み込む」を押します。フォルダ直下のZIPのみが対象です。同じ場所にHTMLを置くだけでは自動読み込みしません。フォルダにZIPがあればJSON・テキストはフォルダ読み込みの対象になりません。

D&D・ファイル選択・フォルダ読み込みは追加読み込みです。000を読んだ後に001を追加すると、不足表示が更新されます。数が多い場合は「ZIPのあるフォルダを読み込む」を使ってください。同じZIPや改名した同一内容のコピーは増やしません。同じ保存操作・分割番号で内容が異なる場合は、先に読み込んだファイルを残して警告します。差し替える場合は「読み込みをクリア」して読み直してください。

保持は画面を開いている間だけです。「読み込みをクリア」やページの再読み込みで解除し、保存ファイルは変更しません。ZIPを保持している間はJSONへ黙って切り替えず、クリアを案内します。保持できるZIPは1000個までです。

同じサイト・アカウントの複数バックアップは、最初に合成して表示します。全体分割ZIPと、後で保存した作品別ZIPを一緒に確認できます。元のZIPは変更しません。「表示するバックアップ」で元の保存操作単位にも切り替えられます。別アカウントは混ぜません。

通常表示は保存日時に基づく最新の版、「取得履歴」は過去の版も表示します。同じ履歴ID・同じ内容は1件、別IDのA→B→Aは3件残します。同じIDで内容が異なる場合は警告し、曖昧な原稿を合成表示から除外します。新しいZIPに存在しない旧データは残します。合成表示には取得再開機能はなく、元の分割不足・破損の警告も保持します。

ZIPの破損検証は表示した項目から行います。未表示項目は未検証です。作品との関連付けはその画面を開いている間だけ有効です。ビューアーは拡張機能・ネット接続不要で、原稿の外部送信・永続保存・ZIPの書き換えを行いません。拡張をOFFまたは削除しても使えます。

Chrome・Firefox・Edgeで利用者による表示・フォルダ読み込み・本文コピーを確認済みです。許可ダイアログや一部の外観は異なります。Firefoxの「アップロード」という確認は選択ファイルをページへ読み込む操作です。このHTMLは外部へ送信しません。コピーできない場合は、選択された文章をCtrl+Cでコピーしてください。

HTMLのダブルクリックでは既定のブラウザが開き、別ウィンドウになるとは限りません。タブを別ウィンドウへ移動して、なろうの編集画面と並べて使えます。

ビューアーHTMLの保存は初期オンで、ZIP保存操作ごとに1つです。同名なら連番を付けます。JSON・テキストだけの保存では追加しません。

## 文字コード・文章の復元

JSONはUTF-8。テキストはUTF-8・UTF-16LE・UTF-16BE、BOMと改行を指定できます。テキスト形式でも確認・再開用JSONをZIPへ同梱します。Shift_JIS・EUC-JP・JISが必要な場合は公式のバックアップ機能をご利用ください。「公式ダウンロード設定の控え」はメモで、公式画面の設定を変更しません。

文章は確認画面からコピーし、なろうの下書きへ手動で貼り付けてください。正しく表示された文章のコピーで、保存ファイルの文字コードの違いによる文字化けは通常起きません。JSONを直接コピーすると改行の\nなどが混ざる場合があるため、ビューアーへ読み込んでください。心配な場合は、テキストを保存時と同じ文字コードで開き、本文だけコピーできます。貼り付け後に改行・前後書き・挿絵コードを確認して保存します。

「編集中の変更を残す」は選んだ入力欄の履歴をブラウザに保存します。なろう公式への保存操作とは別です。作品が確実に特定できない編集履歴は作品別書き出しから除外し、全体保存を案内します。

## 権限と保存範囲

- activeTab：拡張アイコンを押した取得元タブへのアクセス。
- scripting：取得元のアカウント確認とデータの読み取り。
- storage：操作設定・履歴・再開情報のブラウザ内保存。

原稿・設定・利用者IDは暗号化せず保存します。保存先や共有範囲は利用者が管理してください。外部サービスへの原稿送信や自動投稿はありません。旧版の単一ZIP・分割ZIP・旧JSONを読み込めます。過去の版で保存されなかったデータは自動修復できません。
